## 🌟 Overview & Video Inquiries

The **Single-Line Video Prompt Engine (v3.0.0)** is a high-precision cinematic production studio designed for directors, cinematographers, AI video artists, and screenwriters. It compiles complex dramaturgical sequences, character anchors, and physical film stock lighting parameters into continuous, timecoded video windows (e.g., **14.000 seconds per window**, seamless 28s, 56s, or 84s multi-window arcs) formatted with **strictly zero line breaks**.

## 🚀 Key Features

### 1. 🎞️ Agfachrome CT18 Master Plugin (AP-41 Reversal Chemistry)
The flagship Agfachrome CT18 Master Plugin delivers an authentic analog film emulsion:
- **AP-41 Reversal Chemistry**: Emulates the chemical dye-coupler reaction of vintage Agfacolor processing. Delivers delicate watercolor-like pastels, cold sage greens, and muted slate tones.
- **Faded Ocher Highlights & Civilization Decay**: Specially tuned contrast curves simulating civilizational exhaustion and decaying artificial structures through muted amber and warm tungsten filament rolloff.
- **Carl Zeiss Sonnar 40mm f/2.8 HFT & Planar 50mm T1.4 Optics**: Superior microcontrast without artificial edge contrast ringing; captures floating dust motes, micro-fractures, and fabric textures with tactile realism.
- **Velvety D-Max Blacks**: Steep analog density curve producing deep shadow depths while maintaining natural, organic dye-cloud grain across the frame.

### 2. 🎞️ Kodachrome 64 Master Plugin (K-14 Reversal Chemistry)
Uncompromising emulation of the legendary **Kodachrome 64 Daylight (5500K)** reversal slide film:
- **K-14 Subtractive Dye Science**: Three-layer subtractive dye-coupler color separation delivering vivid cinnabar reds, natural peach/olive skin tones, and deep cobalt shadows.
- **Sclera Protection (Anti-Sepia Guard)**: Explicit optical rules preventing the uniform yellow/amber wash common in AI film prompts, keeping the sclera of the eyes naturally ivory-white with neutral specular catchlights.
- **Obsidian D-Max & 650nm Carmine Halation**: Velvety optical blacks combined with natural crimson halation bleeding along high-contrast specular borders.

### 3. 🎞️ CineStill 800T Master Plugin (Tungsten & 650nm Halation)
Dedicated master profile for cinematic night and practical light aesthetics:
- **Remjet Removal Physics**: Simulates Kodak Vision3 500T with the carbon backing mechanically removed, causing intense 650nm carmine-red halos around point light sources.
- **3200K Tungsten Balance**: Balances incandescent lights against rich cyan-cobalt ambient shadows.

### 4. 🎛️ Analog-Trimmer & Lens Emulation Cockpit
Crafted for immediate creative workflow:
- **Category Filter Tabs**: Switch effortlessly between *Favorites, Photo Classics, Cinema, Historic*.
- **Live Indicator Master Panels**: Dedicated, high-visibility cockpits for Agfachrome CT18, Kodachrome 64, CineStill 800T, and Kodak 5247.
- **Collapsible Expert Lab Drawer**: Fine-tune grain size, halation radius, and chemical stress factors (cross-processing, film soup, thermal shock, bleach bypass).

### 5. 📐 Strict Single-Line Window Pressing (0 Line Breaks)
- Every generated window prompt is formatted into **exactly 1 line** of text (0 line breaks).
- Prevents syntax breaks and token drops in diffusion video architectures (MiniMax H3 / Hailuo, Maestro 2.1.6, Kling AI).
- Contiguous timecode stamping:
  - Window 1: `00:00.000 – 00:14.000`
  - Window 2: `00:14.000 – 00:28.000`
  - Window 3: `00:28.000 – 00:42.000`
  - Window 4: `00:42.000 – 00:56.000`
  - Window 5: `00:56.000 – 01:10.000`
  - Window 6: `01:10.000 – 01:24.000`

### 6. 🧠 Local LM Studio Integration (Private Vision & Text AI)
- Connects directly to local **LM Studio** instances (`http://localhost:1234/v1/chat/completions`) via built-in proxy gateway.
- Fully private: No cloud API keys required for local processing.
- Executes multi-task visual reference analysis for uploaded images (persons, companion pets, architectural facades, floorplans, props).

### 7. 🗺️ Multimodal Floorplan & Architectural Layout Analysis
- Reads architectural blueprints and floorplan drawings (`PNG`, `JPG`, `WebP`).
- Extracts room axes, entrance foyers, kitchen island locations, and sightlines.
- Translates spatial directions into continuous camera moves (`Steadicam dolly-in along sightline...`).

### 8. 🏷️ Identity & Character Anchoring (`compactPromptAnchor`)
- Locks character features (hair, eyes, age, clothing, facial structure) and prop details using **Maestro 2.1.6** binding tags (`@Subject1_...`, `@Building1_...`, `@Object1_...`, `@Logo1_...`).
- Prevents identity cross-bleeding and character cloning across multi-window video sequences.

### 9. 👆 Interactive 1-Click Reference Chips & Scenario Presets

- 🎯 **Recommended Maestro GUI Weight**: `0.85 – 1.00`

### LoRA Guidelines & Disentanglement:
- **When to Enable**: Ideal for architectural lighting, complex spatial blocking, Dutch angles, aerial perspectives, and atmospheric volumetric fill.
- **When to Disable**: When executing strict, color-critical photochemical film emulations (such as **Agfachrome CT18** or **Kodachrome 64**), turn the LoRA off. Because Astroburner's LoRA carries a heavy film noir / monochrome bias, turning it off allows the authentic AP-41 and K-14 color chemistry to shine without unwanted desaturation or amber distortion.

## ⚡ Quick Start

### 1. Prerequisites
- Node.js (v18+ recommended)
- Optional: Local [LM Studio](https://lmstudio.ai/) running with local server enabled on port `1234`.

### 2. Development Setup
```bash
# Install dependencies
npm install

# Start the dev server (runs on port 3000)
npm run dev
```

### 3. Production Build
```bash
# Build static assets & bundle server
npm run build

# Start production server
npm start
```

## 📋 Recommended Production Workflow

1. **Upload References (Step 1)**:
   - Drag & drop images of characters, companion subjects, buildings, architectural floorplans, or props into the **Reference Manager**.
   - Click **"Send All Tasks to LM Studio"** to extract vision anchors automatically.

2. **Select Analog Film & Lens Profile (Step 2)**:
   - Open **Drehbuch-Konfigurator** -> **Analog-Trimmer & Linsen-Emulation**.
   - Select **Agfachrome CT18 Master Plugin** for the AP-41 reversal chemistry look with cold sage shadows and watercolor pastels.

3. **Configure Scenario & LoRA (Step 3)**:
   - Load a scenario preset (e.g., *Agfachrome CT18: Das Erlöschen des Spektrums* or *Elemental Matter*).
   - When using Agfachrome CT18 or Kodachrome 64, leave the Astroburner LoRA turned off for pure reversal color fidelity, or enable it when building moody architectural shots.

4. **Press into Single-Line Windows (Step 4)**:
   - Click **"Press into Single-Line Windows"**.
   - Copy prompts directly into **MiniMax H3 / Hailuo**, **Maestro 2.1.6**, or **Kling AI**.
